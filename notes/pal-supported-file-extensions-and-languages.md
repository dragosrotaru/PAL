# Pal supported file extensions and languages

First-party support planned across all categories. Level of integration will vary.

## Host / native languages

- Rust
- Pal
- Pretty (DSL)

## Foreign languages

- JavaScript / JSX
- TypeScript
- Python

## Data formats

- Text
- JSON
- CSV / Excel
- YAML
- XML

## Presentation

- HTML / CSS
- SVG
- Markdown
- 3D formats
- LaTeX
- PDF
- Word Docs

## Visual media

- JPEG
- PNG
- GIF
