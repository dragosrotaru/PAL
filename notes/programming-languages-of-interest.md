# Programming languages of interest

## Logic and proof languages

- [Agda](https://en.wikipedia.org/wiki/Agda_(programming_language)) — dependently typed, proof assistant
- [Coq](https://en.wikipedia.org/wiki/Coq) — proof assistant / certified programming
- [Prolog](https://en.wikipedia.org/wiki/Prolog) — logic programming

## Functional

- [Haskell](https://en.wikipedia.org/wiki/Haskell) — pure FP, strong type system
- [OCaml](https://en.wikipedia.org/wiki/OCaml) — pragmatic FP with imperative escape hatches
- [Erlang](https://en.wikipedia.org/wiki/Erlang_(programming_language)) — actor model, fault-tolerant
- [Scala](https://en.wikipedia.org/wiki/Scala_(programming_language))
- [Racket](https://en.wikipedia.org/wiki/Racket_(programming_language)) — language-oriented programming
- [Scheme](https://en.wikipedia.org/wiki/Scheme_(programming_language))
- [Clojure](https://en.wikipedia.org/wiki/Clojure) — JVM Lisp
- [Common Lisp](https://en.wikipedia.org/wiki/Common_Lisp)

## Multiparadigm / novel

- [Oz](https://en.wikipedia.org/wiki/Oz_(programming_language)) — multiparadigm, constraint programming
- [Smalltalk](https://en.wikipedia.org/wiki/Smalltalk) — pure OO, live environment
- [Lucid](https://en.wikipedia.org/wiki/Lucid_(programming_language)) — dataflow / demand-driven
- [Icon](https://en.wikipedia.org/wiki/Icon_(programming_language)) — goal-directed evaluation
- [Forth](https://en.wikipedia.org/wiki/Forth_(programming_language)) — stack-based, minimal, concatenative

- Lua
